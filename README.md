# 🛰 ОРБИТА-9

Текстовая ролевая игра про космическую станцию, которая ломается.
Ты просыпаешься в медотсеке через сорок часов после аварии и должна решить,
что делать с семью людьми, одним реактором и сигналом из атмосферы газового гиганта.

**Три финала. Ни одного правильного.**

Игра работает в браузере — на телефоне и на компьютере. Ничего устанавливать не нужно.

---

## Как запустить

### Вариант 1 — самый простой (без команд)

1. Открой папку проекта.
2. Дважды щёлкни по `index.html`.

Игра откроется в браузере. Всё.

> Одна оговорка: при таком способе некоторые браузеры могут не дать игре
> сохранять прогресс. Если «Продолжить» не появляется — используй вариант 2.

### Вариант 2 — через локальный сервер (рекомендуется)

Нужен Python — он уже установлен на macOS и Linux, на Windows ставится с python.org.

```bash
# зайди в папку проекта
cd testing

# запусти маленький сервер
python3 -m http.server 8080

# открой в браузере
# http://localhost:8080
```

На Windows вместо `python3` обычно пишут `python`.

Чтобы остановить сервер — нажми `Ctrl + C`.

## Как играть

1. Нажми **«Новая игра»**.
2. Выбери, кем ты была до аварии: **Техник**, **Связист** или **Психолог**.
   Это не «сложность», а разные ключи к одним и тем же дверям.
3. Читай сцену и выбирай вариант ответа.
4. Смотри на подписи над кнопками: `[🔧 Ремонт 2 · шанс 62%]` — это проверка навыка.
   Шанс честный, игра его показывает.
5. Кнопки в правом верхнем углу: **📊** навыки, **🎒** сумка, **📖** дневник.
6. Прогресс сохраняется сам после каждого выбора. Закрыть вкладку не страшно.

## Что внутри проекта

```
testing/
├── index.html          ← «рамка» игры: экраны, кнопки, места под текст
├── src/
│   ├── styles.css      ← внешний вид: цвета, шрифты, удобство на телефоне
│   ├── state.js        ← память игры: навыки, сумка, флаги, сохранение
│   ├── ui.js           ← «руки»: рисует сцену на экране
│   ├── game.js         ← «мозг»: правила проверок, переходы, дневник
│   └── story/
│       ├── chapter1.js ← Глава I. Пробуждение
│       ├── chapter2.js ← Глава II. Три двери
│       └── chapter3.js ← Глава III. Три финала
├── assets/art/web/     ← 10 иллюстраций сцен (сжатые под телефон)
├── docs/               ← шпаргалки простыми словами
├── test/harness.js     ← автотест: прогоняет 360 прохождений
├── ROADMAP.md          ← план проекта по шагам
├── DECISIONS.md        ← почему выбраны именно такие решения
└── CHANGELOG.md        ← что и когда менялось
```

**Главная мысль устройства:** история отдельно, механика отдельно.
Тексты лежат в `src/story/`, а правила — в `src/game.js`.
Поэтому можно дописывать сцены годами, не трогая «мозг» игры.

## Как добавить свою сцену

1. Открой `src/story/chapter1.js` (или любой другой).
2. Скопируй любую сцену целиком.
3. Поменяй `STORY.имя_сцены` на своё, например `STORY.moyа_komnata`.
4. Напиши текст в `text: [ ... ]` — каждый элемент массива это отдельный абзац.
5. В `choices` укажи, куда ведёт кнопка: `next: "имя_другой_сцены"`.
6. Вставь ссылку на новую сцену из какой-нибудь существующей.

Пример — самая простая сцена:

```js
STORY.moya_komnata = {
  chapter: 1,
  title: "Кладовая",
  text: [
    "Ты открываешь дверь и находишь ящик с настоящим кофе.",
    "На станции, где всё кончилось, это почти чудо."
  ],
  choices: [
    { label: "Взять банку", next: "corridor", give: "Банка кофе" },
    { label: "Оставить. Пусть найдёт кто-то другой", next: "corridor" }
  ]
};
```

Проверить, что ничего не сломалось:

```bash
node test/harness.js
```

Если в ответе «ВСЁ ЧИСТО» — игра проходится от начала до конца
по всем трём финалам и ни одна кнопка не ведёт в пустоту.

## Как проверить, что всё работает

1. Открывается стартовый экран с названием «ОРБИТА-9».
2. Кнопка «Новая игра» показывает три карточки героя.
3. После выбора героя появляется медотсек с картинкой и тремя вариантами.
4. В коридоре доступны Ковач, Ирис, реактор, шлюз и «Пора решать».
5. На развилке у реактора видно `[🔧 Ремонт 3 · шанс …%]`, и результат бывает разным.
6. Дойди до конца — увидишь финал и список всех своих решений.
7. Закрой вкладку, открой заново — появится «Продолжить».
