# Сводная статистика живых прогонов

Источники: живой каскад 6 задач, A/B sequential/hedged, накопление по раундам.

- Всего модельных срезов (без квотных отказов): 9, решено: 9, из них tier-0: 4 (44%)
- Отказов по дневной квоте free tier (429, не провалы моделей): 15
- Медиана времени решённой задачи: 17.2 с; медиана токенов: 2363

Главное ограничение метода: дневная квота free tier — 50 запросов/день на ключ; накопление 5 раундов уперлось в неё целиком (все 15 попыток раундов — 429). Статистика выше поэтому собрана из срезов до исчерпания квоты; для честных медиан по раундам нужен либо другой день, либо платный ключ.
