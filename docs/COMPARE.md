# Конкурентное сравнение (автогенерация: bench_compare.py --write)

Одна задача: поиск -> top(2) -> форматирование. Локальная машина, прогрев включён.

| Участник | мкс/запуск | Примечание |
|---|---:|---|
| Чистый Python (потолок) | 0.1 | — |
| Pick Интерпретатор | 34.9 | 297x от потолка |
| Pick Авто (AOT) | 5.1 | 43.8x от потолка, 6.8x быстрее интерпретатора |
| LangGraph (3 узла, без чекпоинтера) | 787.2 | 6702x от потолка |
| DurableWeave (SQLite, журнал+хэш-цепочка+CAS) | 578.0 | 4921x от потолка — цена краш-устойчивости и аудита |

Честные оговорки: LangGraph меряется без чекпоинтера (его durable-режим дороже); DurableWeave — единственный участник, пишущий журнал с хэш-цепочкой и CAS на каждый шаг, поэтому его цифра — цена гарантий, а не оверхед ради оверхеда. Чистый Python не даёт ни replay, ни аудита, ни лимитов — это потолок, а не конкурент по функциям.
