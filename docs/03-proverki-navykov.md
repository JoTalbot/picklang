# Как работают проверки навыков

Это самая «фоллаутовская» механика в игре. Разберём её до конца,
чтобы ты могла её менять осознанно, а не наугад.

---

## Зачем проверка вообще нужна

Без проверки выбор — это просто «нажми и получи». С проверкой у выбора
есть **ставка**: может получиться, может нет.

И вот главное: **провал — не наказание. Провал — это другая история.**
В Fallout 2 провал взлома не заканчивает игру, он открывает дверь,
которую ты не планировала открывать.

---

## Формула в нашем проекте

```
шанс = 0.5 + 0.18 × (навык − сложность) + 0.04 × удача
границы: от 5% до 95%
```

В коде (`src/game.js`):

```js
function chance(skillValue, dc, luck) {
  let p = 0.5 + 0.18 * (skillValue - dc) + 0.04 * (luck || 0);
  return Math.max(0.05, Math.min(0.95, p));
}
```

`Math.max(0.05, Math.min(0.95, p))` — это «зажать» число в рамки.
Если получилось −3, станет 0.05. Если получилось 10, станет 0.95.

---

## Что это значит на практике

| Навык | Сложность | Удача | Шанс |
|---|---|---|---|
| 1 | 1 | 0 | 50% — монетка |
| 3 | 1 | 1 | 90% — почти наверняка |
| 1 | 3 | 0 | 14% — отчаянная попытка |
| 2 | 2 | 2 | 58% — чуть лучше монетки |

Обрати внимание: **проиграть можно всегда** (минимум 5%),
и **выиграть нельзя наверняка** (максимум 95%). Это сделано специально:
игра, где нет риска, — это не игра, а кнопка «продолжить».

## Как проверка записывается в данных

Вот кнопка, которая требует Ремонт 3:

```js
{
  label: "Вернуть реактору полную мощность",
  next: "reactor_repair",          // если получилось
  fail: "reactor_repair_fail",     // если нет
  check: { skill: "repair", dc: 3 },
  successNote: "Реактор стабилен",
  failNote: "Контур не выдержал"
}
```

Читается по-человечески: «если щёлкнешь — бросаем кубик на Ремонт против
сложности 3; при успехе идём в `reactor_repair`, при провале — в `reactor_repair_fail`».

---

## Почему шанс показывается игроку

Потому что скрытая вероятность — это не напряжение, а несправедливость.
Когда видно «шанс 14%», ты принимаешь **решение**, а не тянешь лотерею.

---

## Как это настроить под себя

Хочешь, чтобы игра была добрее? Поменяй `0.18` на `0.25` — навык будет
сильнее влиять на исход, и провалы станут реже.

Хочешь жёстче? Подними базовые 50% до 40%... или понизь до 35%.

**Но:** после любой правки запусти `node test/harness.js`.
Формула меняет только шансы, поэтому тест не должен упасть,
но привычку проверять лучше заводить сразу.
