# Данные, объекты и массивы

Почти вся игра — это правильная упаковка информации.
Разберём три слова, которых новички боятся больше всего.

---

## Данные — это просто «что храним»

Текст сцены — данные. Список предметов — данные. Цифра «Ремонт 3» — данные.

**Почему их отделяют от кода:** если текст лежит отдельно от правил,
его можно менять, не рискуя что-то сломать. Как инструкция рядом с прибором,
а не выцарапанная на его микросхеме.

---

## Массив — список

**Что это:** упорядоченный список чего угодно.

```js
let bag = ["Ремкомплект", "Ключ-карта"];
```

**Аналогия:** сумка, в которой вещи лежат по порядку и у каждой есть номер.
Нумерация начинается с **нуля** — это первое, обо что спотыкаются все:

```js
bag[0]   // "Ремкомплект"
bag[1]   // "Ключ-карта"
bag.length // 2
```

**Добавить в конец:** `bag.push("Обломок стекла")`
**Найти:** `bag.indexOf("Ключ-карта")` → вернёт `1`, а если нет — вернёт `-1`
**Убрать:** `bag.splice(1, 1)` → убрать 1 элемент начиная с позиции 1

**В нашем проекте:** `state.items` — сумка героя.
А `text: ["абзац 1", "абзац 2"]` — массив абзацев сцены.

## Объект — коробка с подписанными отделениями

**Что это:** набор «имя → значение».

```js
let hero = {
  name: "Техник",
  repair: 3,
  luck: 1
};
```

**Аналогия:** аптечка с подписанными ячейками. Не «третья ячейка сверху»,
а «ячейка БИНТ». Найти нужное можно сразу, не считая.

**Достать значение:** `hero.repair` → `3`

**В нашем проекте:** вся память игры — это один большой объект `state`:

```js
state = {
  scene: "corridor",      // где мы сейчас
  skills: { repair: 3 },  // навыки
  items: ["Ремкомплект"], // сумка
  flags: { kovachGave: true }, // решения
  suit: 4                 // скафандр
}
```

## Флаги — самый важный приём в этой игре

**Флаг** — это объект, где лежат только «да/нет» про то, что произошло.

```js
state.flags.savedTech = true;
```

Потом любая сцена может спросить:

```js
if (state.flags.savedTech) {
  return ["Техник садится рядом с тобой у пульта."];
}
```

**Почему это гениально просто:** не нужно делать отдельную копию игры
для каждого варианта прошлого. Одна игра, много флагов — и из них
складывается уникальная история каждой игроки.

Именно так работают почти все RPG с выборами — от Fallout до Disco Elysium,
просто у них флагов десятки тысяч, а не двадцать.

## Мини-упражнение

Попробуй ответить, что выведет код:

```js
let bag = ["Карта"];
bag.push("Ключ");
console.log(bag.length, bag[0], bag[1]);
```

<details>
<summary>Ответ</summary>

`2 "Карта" "Ключ"` — длина стала 2, нумерация с нуля,
поэтому первый элемент это `bag[0]`.
</details>
