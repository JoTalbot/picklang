# Скоростные замеры (автогенерация: bench_speed.py --write)

| Замер | Значение |
|---|---|
| Один шаг: интерпретатор | 3.0 мкс |
| Один шаг: AOT (скомпилировано) | 0.5 мкс |
| AOT против интерпретатора | 6.4x быстрее |
| Цикл 200 элементов: по одному | 1.9 мс |
| Цикл 200 элементов: batch | 0.0 мс |
| Resume 60 шагов со снимками | 1.8 мс, снимок использован: True, новых вызовов: 0 |

Методика: локальная машина, прогрев перед замером интерпретатора/AOT; для сетевых инструментов цифры будут определяться сетью, а не рантаймом.
