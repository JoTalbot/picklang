# Что такое HTML, CSS и JavaScript — на пальцах

Три языка, из которых состоит любая страница в интернете.
В нашем проекте это ровно три файла-роли.

---

## HTML — скелет

**Что это:** язык разметки. Ты пишешь «вот тут заголовок, вот тут кнопка»,
браузер рисует.

**Аналогия:** каркас дома. Стены, комнаты, дверные проёмы. Ещё без обоев
и без мебели, но уже можно понять, где что будет.

**Главные «кирпичики»:**

| Тег | Что делает | Аналогия |
|---|---|---|
| `<div>` | невидимая коробка-контейнер | полка |
| `<h1>`, `<h2>` | заголовок | надпись над дверью |
| `<p>` | абзац текста | страница книги |
| `<button>` | кнопка | кнопка звонка |
| `<img>` | картинка | плакат на стене |
| `<section>` | большой блок-экран | комната |

**В нашем проекте:** `index.html`. Там лежат четыре «комнаты»:
стартовый экран, выбор героя, игра, финал.

---

## CSS — внешний вид

**Что это:** язык оформления. Цвета, размеры, отступы, шрифты.

**Аналогия:** обои, краска и мебель. Дом тот же, жить приятнее.

**Одна строка CSS** состоит из «кого красим» и «как»:

```css
.btn {
  padding: 16px;      /* отступ внутри кнопки */
  border-radius: 14px; /* скругление углов */
  font-size: 15px;     /* размер текста */
}
```

Читается: «всё, у чего есть класс `btn`, получает такие-то свойства».

**Что такое класс:** ярлык на элементе. В HTML пишешь `<button class="btn">`,
и CSS по этому ярлыку находит элемент. Один ярлык — много элементов разом.

**В нашем проекте:** `src/styles.css`. Ключевая идея — «сначала удобно
на телефоне»: крупный текст, кнопки во всю ширину, ничего не уезжает за край.

---

## JavaScript — поведение

**Что это:** язык программирования, который работает прямо в браузере.
Это единственный язык, который браузер понимает без установки чего-либо.

**Аналогия:** электрика и проводка. Дом стоит, но пока не щёлкнешь
выключатель — ничего не происходит.

**Три вещи, которых достаточно для 90% игр:**

```js
// 1. Переменная — подписанная коробка
let suit = 4;

// 2. Условие — «если... то...»
if (suit <= 2) {
  console.log("Опасно");
}

// 3. Действие в ответ на нажатие
button.addEventListener("click", function () {
  suit = suit - 1;
});
```

**В нашем проекте:** `src/game.js` (правила) и `src/ui.js` (рисование).

---

## Как они работают вместе

```
HTML   →  «где что лежит»        (кнопка существует)
CSS    →  «как это выглядит»      (кнопка большая и оранжевая)
JavaScript → «что происходит»     (нажала — перешли в другую сцену)
```

Один элемент, три роли. Именно поэтому HTML без JS — это красивая
неподвижная картинка, а JS без HTML — это код, которому нечего показать.
