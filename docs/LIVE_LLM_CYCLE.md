# Живой LLM-цикл через OpenRouter (проведён 2026-10-19, по этапам)

Ключ — бесплатный тариф OpenRouter, цена всех вызовов $0. Ключ в репозиторий не попадал.
Токены ниже — фактический `usage` из ответов API, а не оценка.

## Этап A: намерение -> программа -> исполнение (модель cohere/north-mini-code:free)

- usage: prompt 314, completion 2 376, всего 2 690. Из completion **2 216 — скрытое
  рассуждение модели**; сам JSON намерения — см. payload-разрез ниже.
- Модель вернула корректное намерение с первого раза: create_sub с undo,
  блоки `pay`/`notify` через `use`, результат `{sub, tx}`.
- Генератор + словарь собрали программу (7 строк), исполнение:
  `CRASHED` (искусственное падение после закоммиченного шага) -> `COMPLETED`,
  списаний у банка: 1, verify по digest: True.

## Этап B: та же задача — «напиши Python целиком»

- cohere/north-mini-code:free на этой формулировке **дважды не ответила за 115–170 с**
  (на намерении та же модель ответила за ~33 с).
- Ответ получен от poolside/laguna-s-2.1:free за 3 с: prompt 312, completion 98, всего 410.
- Качество: код вернулся **в markdown-ограждении вопреки инструкции** (как Python не
  компилируется) и **выдумал функции pay()/notify()**, которых нет среди функций хоста.
  То есть классический путь на слабой модели дал невалидный результат, который ещё
  предстояло бы чинить дополнительными итерациями.

## Выводы (осторожные: модели на этапах разные, бесплатный тариф нестабилен)

1. Главный потребитель токенов у reasoning-моделей — скрытое рассуждение, а не
   формат ответа: оно одинаковым налогом ложится на оба пути. Формат экономит
   payload и, главное, число итераций исправления.
2. Путь A оказался устойчивее к слабой модели: ограниченная грамматика намерения
   не дала выдумать несуществующие функции — словарь и генератор приняли только
   известное, а исполнение сразу прошло durable-проверку.
3. Путь B на той же задаче дал невалидный код, требующий минимум ещё одного
   цикла «ошибка -> перепиши», который в замер не вошёл.
4. Воспроизводимость: `live_cycle_openrouter.py --key-file <файл>` (ключ только
   в заголовке запроса). Стабильность бесплатных моделей не гарантируется:
   429 и зависания наблюдались прямо в этом прогоне.
