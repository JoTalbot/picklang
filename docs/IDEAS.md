# Идеи улучшения (приоритет — по отдаче на токен/усилие)

Статус: пункты 1–7 первой волны реализованы (см. README), ниже — исходные формулировки и что осталось.

## Язык и экономия токенов
1. **Словарь проекта (vocabulary) в CAS.** Проект один раз дорого описывает свои
   блоки («оплата», «нотификация», типовые стражи); дальше LLM ссылается на
   короткий алиас блока по digest вместо перепечатывания. Это вторая по величине
   экономия после diff-режима.
2. **Сжатие идентификаторов по частоте.** Переименование переменных/функций в
   1–2-символьные имена на этапе «LLM пишет» с обратной развёрткой для человека
   (source-map). Токенизатор режет длинные идентификаторы на куски — короткие
   имена реально дешевле.
3. **Генератор программ из намерения (Genesis-направление).** LLM пишет не код,
   а цель+ограничения; компилятор достраивает типовую механику (ретраи, стражи,
   компенсации) по шаблонам. Модель платит только за то, что уникально.
4. **Автоподсказка ошибок в формате патча.** Парсер/верификатор возвращают не
   текст ошибки, а готовый diff `~N: ...`, применимый одной операцией.
5. **Типовой контроль IR до исполнения.** Дешёвая статическая проверка
   (неизвестная функция, поле не того результата) ловит ошибки без запуска —
   каждый несостоявшийся запуск экономит весь цикл «запуск→ошибка→перепиши».

## Исполнение и надёжность
6. **Настоящий Temporal-адаптер**: тот же IR исполняется Temporal Workflow,
   где каждая строка PICK = Activity. Язык не меняется, рантайм заменяется.
7. **Таймеры и дедлайны в `@wait approval :24h`** с эскалацией при истечении.
8. **Параллельные ветки**: `x = a.f() | b.g()` — независимые шаги одним символом,
   frontier-исполнение вместо последовательного.
9. **Спекулятивное исполнение**: ветка помечается `~>`, её результаты не
   authoritative, пока страж/человек не подтвердит (идея speculation из Prolepsis).

## Доказуемость и экосистема
10. **Подпись digest исполнения внешним ключом** — аудит-трейл, пригодный для спора.
11. **Публичный корпус бенчмарков**: 20–30 типовых задач в PICK/Python/JSON с
    автоматическим пересчётом токенов в CI — чтобы «в N раз дешевле» было цифрой
    из репозитория, а не лозунгом.
12. **Интеграция с MCP**: хост-функции PICK = MCP-инструменты; любой MCP-сервер
    автоматически становится библиотекой языка.
