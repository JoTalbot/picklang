4. Скорость исполнения (новый замер)

Прямой вызов функции: ~0.1 мкс. Тот же вызов через PICK-интерпретатор: 69.5 мкс на программу из одного шага — почти всё время уходит на повторный парсинг исходника при каждом запуске.

Параллельные ветви: 2 ветви по 200 мс — последовательно 0.40 с, через || — 0.20 с (2.0x).

Для агентных задач, где шаг — это сетевой вызов на 100–2000 мс, 70 мкс интерпретатора незаметны. Но для тысяч мелких шагов и для eval-прогонов компиляция программы один раз даст порядок скорости почти даром.
